🚀 4. Permanent Link Setup on GitHub (Free Forever)
  1. Create a new repository on GitHub.com (e.g. named living-memory).
  2. Upload all files from this folder into the repository.
  3. Replace photo.jpg and video.mp4 with your own photo and video.
  4. Put the compiled targets.mind file into the repository root.
  5. In your repository, click Settings → Pages.
  6. Under Branch, select main and folder / (root), then click Save.
  7. Within 1-2 minutes, GitHub gives you your permanent HTTPS link: https://<your-username>.github.io/<repo-name>/!
